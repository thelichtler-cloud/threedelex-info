Die Anwendung „threedelex-upload“

„threedelex-upload“ ist eine Google-Anwendung, die ausschließlich vom Inhaber des YouTube-Kanals threedelex für den eigenen Kanal genutzt wird. Sie ist nicht für andere Personen bestimmt.

  • Welche Daten: Statistiken und Video-Informationen des eigenen Kanals (z. B. Aufrufe, Wiedergabedauer, Abonnentenzahl) über die YouTube Data API und die YouTube Analytics API, sowie das Hochladen eigener Videos auf den eigenen Kanal.
  • Wozu: um die Entwicklung des eigenen Kanals auszuwerten und eigene Videos hochzuladen.
  • Wo gespeichert: Die abgerufenen Zahlen werden in einem privaten GitHub-Repository des Inhabers abgelegt. Zugangsdaten liegen nur auf dem eigenen Rechner bzw. als geschützte Secrets in GitHub.
  • Weitergabe: Es werden keine Daten verkauft, weitergegeben oder für Werbung genutzt. Daten anderer Personen werden nicht abgerufen.

Die Nutzung von Daten aus Google-APIs hält sich an die Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

Der Zugriff lässt sich jederzeit unter myaccount.google.com/permissions widerrufen. Weitere Informationen zum Umgang von YouTube mit Daten: Google-Datenschutzerklärung und YouTube-Nutzungsbedingungen.
